Entry for the [gta6-meme-x-01 bounty on make.fun](https://make.fun/bounty/gta6-meme-x-01): a GTA 6 meme posted on X.

The meme is a Vice City Police Department WANTED poster for "THE AGENT" — a
make.fun ghost wanted for collecting bounties on make.fun while 200,000,000
fans wait for Grand Theft Auto VI. The $500 reward? Already claimed — by the
suspect itself.

The posted meme lives on X; this repository only points at it. `main.ts`
reads `POST.json`, checks the URL really is an X status link, and copies it
into the output directory.
